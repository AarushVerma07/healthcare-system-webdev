Tests We Provide

Test Detail: Blood Test (CBC)

Test Name: Complete Blood Count (CBC)
Purpose: To check overall health and detect anemia, infection, or leukemia.
Sample Required: 2 ml venous blood (EDTA vial)
Preparation Instructions: No special preparation needed. Fasting is not required for this test.
Normal Reference Range: Hemoglobin: 12.0–17.5 g/dL, WBC: 4,500–11,000 /µL
Report Delivery Time: Same day, within 6 hours

Test Detail: Routine Urine Analysis

Test Name: Routine Urine Analysis
Purpose: To detect urinary tract infections, kidney disease, and diabetes.
Sample Required: 10–15 ml mid-stream urine sample (sterile container)
Preparation Instructions: First morning urine sample is preferred. No strict fasting required.
Normal Reference Range: Clear, pH 4.6–8.0, Protein/Glucose: Negative
Report Delivery Time: Same day, within 6 hours

Test Detail: LFT

Test Name: LFT
Purpose: To evaluate liver health, enzyme levels, and protein production.
Sample Required: 3-5 ml venous blood (SST/plain vial)
Preparation Instructions: Strict fasting is required for 8–12 hours. Only plain water is allowed.
Normal Reference Range: Multiple markers (e.g., Bilirubin: 0.1–1.2 mg/dL, ALT: 7–56 U/L)
Report Delivery Time: Same day, within 6-12 hours

Test Detail: Thyroid Profile

Test Name: Thyroid Profile (T3, T4, TSH)
Purpose: To assess thyroid gland function and diagnose thyroid disorders.
Sample Required: 3 ml venous blood (SST/plain vial)
Preparation Instructions: No special preparation needed. Fasting is not required, but morning sample collection before thyroid medication is recommended.
Normal Reference Range: TSH: 0.4–4.0 mIU/L, T3: 80–200 ng/dL, T4: 5.0–12.0 µg/dL
Report Delivery Time: Same day, within 12 hours

Test Detail: KFT

Test Name: KFT (Kidney Function Test)
Purpose: To check kidney performance and monitor metabolic waste filtration.
Sample Required: 3 ml venous blood (SST/plain vial)
Preparation Instructions: No special preparation needed. Fasting is not required, but stay adequately hydrated.
Normal Reference Range: Serum Creatinine: 0.6–1.2 mg/dL, BUN: 7–20 mg/dL
Report Delivery Time: Same day, within 6 hours

Test Detail: Lipid Profile

Test Name: Lipid Profile
Purpose: To measure cholesterol and triglyceride levels for evaluating cardiovascular health.
Sample Required: 3 ml venous blood (SST/plain vial)
Preparation Instructions: Strict fasting is required for 10–12 hours. Only plain water is allowed.
Normal Reference Range: Total Cholesterol: Below 200 mg/dL, HDL: Above 40 mg/dL, LDL: Below 100 mg/dL
Report Delivery Time: Same day, within 8 hours

Test Detail: Diabetes Tests

Test Name: Diabetes Profile (HbA1c / Fasting Blood Sugar)
Purpose: To measure average blood sugar levels and diagnose/monitor prediabetes and diabetes.
Sample Required: 2 ml venous blood (EDTA / Fluoride vial)
Preparation Instructions: 8–10 hours fasting required for FBS (Fasting not required if taking HbA1c only).
Normal Reference Range: HbA1c: Below 5.7%, Fasting Glucose: 70–99 mg/dL
Report Delivery Time: Same day, within 4–6 hours
